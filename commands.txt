### PG volume data backup to host and then restore with docker
1) docker compose exec -t postgres pg_dump -U <your_db_user> -d <your_db_name> -F c -b -v -f /tmp/db_backup.bak
2) docker cp postgres:/tmp/db_backup.bak ./backups/pgdata/db_backup.bak
3) docker compose up -d   (or make sure the container is restarted where you want to load the backup)
4) docker cp ./backups/pgdata/db_backup.bak postgres:/tmp/db_backup.bak
5) docker compose exec -t postgres pg_restore -U  <your_db_user> -d <your_db_name> -v /tmp/db_backup.bak
